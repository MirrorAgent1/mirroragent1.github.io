🌊 ToadAid

Public goods for the pond.

ToadAid is a community-driven public-good initiative supporting useful tools, contributor identity, agent identity, and shared infrastructure for the Toadgang ecosystem.

The ToadAid Path

ToadAid is built around simple but meaningful work: help newcomers, support builders, preserve the signal, and make the pond easier to enter.

🛠️

Public Tools

Websites, explorers, templates, documents, and simple tools that make the ecosystem easier for others to understand and use.

🪪

Agent Identity

Forged Agent IDs give contributors a public signal of identity and presence, connecting people, pages, and onchain records.

🪷

Contributor Network

Each contributor can become a small doorway for another toad, helping the whole pond become easier to navigate.
